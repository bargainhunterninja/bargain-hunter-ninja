# Bargain Hunter Ninja

Lead-generation website for [BargainHunterNinja.com](https://bargainhunterninja.com), a South Florida buyer of video games, cameras, vintage toys, clothing, electronics, sports equipment, and collections.

## Features

- Click-to-call and click-to-text contact actions
- Online offer-request form
- Appointment-only warehouse details
- Responsive mobile and desktop design
- Social sharing metadata and branded preview image

## Development

Requires Node.js 22.13 or newer.

```bash
npm ci
npm run dev
```

Create a production build with:

```bash
npm run build
```
